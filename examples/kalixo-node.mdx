This is a **reference implementation** - copy [`client.js`](/examples/kalixo-node/client.js) into
your project or adapt it. It is not published to npm.

## Features

- `KalixoClient.sandbox()` / `.production()` factory helpers
- `placeOrder()` with your `externalOrderCode` idempotency key and per-line `country`
- `waitForOrder()` - waits until `estimatedReadyAt`, polls every 60s, and gives up after a
  maximum wait (2 hours by default)
- Retries `429` (using `Retry-After`), `5xx` and network errors with backoff
- `KalixoError` with `statusCode` and the `X-Request-Id` to quote to support
- `newExternalOrderCode()` helper for stable idempotency keys

## Usage

```javascript
import { KalixoClient, newExternalOrderCode } from './client.js';

const kalixo = KalixoClient.sandbox(process.env.KALIXO_API_KEY);

const { products } = await kalixo.listProducts({ country: 'GB', take: 5 });
const product = products[0];

const externalOrderCode = newExternalOrderCode(); // store it before you send the order

const accepted = await kalixo.placeOrder({
  externalOrderCode,
  currency: product.currencyCode,
  orderProducts: [
    {
      productCode: product.productCode,
      country: product.countryCode, // required for products with several availableCountries
      price: product.price,
      quantity: 1,
    },
  ],
});

console.log('Processing until', accepted.estimatedReadyAt);

const order = await kalixo.waitForOrder(accepted.orderId, accepted.estimatedReadyAt);

if (order.status === 'failed') {
  console.error(order.reason);
} else {
  // completed: every code; partially_completed: the delivered codes only
  console.log(order.products.flatMap((line) => line.codes));
}
```

<Note>
  Requires Node 18+ (`fetch` built in) and ES modules (`"type": "module"` or a `.mjs` file).
  For older Node versions, swap `fetch` for your HTTP library.
</Note>
